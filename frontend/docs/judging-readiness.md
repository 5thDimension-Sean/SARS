## Demo and references preparation

The supplied guide permits a **maximum seven-slide deck, including title/intro slides, or a video of 30 seconds or less**. A 90-second site walkthrough, if added later, is an on-site help feature and is not a compliant substitute for that demo. Keep a possible deck to: team/challenge; user problem; proposed experience; real NASA data; a concrete user journey; validity/limits; benefit and next step. Team identity and challenge wording require the team's confirmation before a final presentation is produced.

The guide requires English linked materials, with English subtitles if a video uses another spoken language. It also requires accessible demo/project links and references for external code, text, images, data and tools. Private Figma and repository links are development artifacts, not verified judge-accessible final links. Access settings have not been changed.

AI assistance is disclosed visibly on both site routes and in page metadata for interface design and code. Published NASA-derived measurements were preserved; the redesign does not generate measurement imagery. The guide requires visible indicators on generated media; no image-generation tool was used for the radar imagery. Any later pitch assets should retain the appropriate disclosure and avoid NASA logos or fabricated branding.

Reference inventory to reconcile against final use: NASA NISAR L2 GCOV provisional; ASF DAAC; CMR granule records and dataset DOI; optional NASA GIBS; Next.js, React, MapLibre GL, Tailwind and the existing UI libraries; ChatGPT, Figma and Lovable for design/development assistance. Existing California incident photographs retain their upstream source/credit metadata and are not displayed as pixel-aligned optical evidence by this redesign.

Do not submit for judging, accept submission declarations, change public sharing, publish the site or send the project to anyone. The user has explicitly prohibited submission. Keep readiness notes and repository/design work separate from the official submission form. Registration, team membership, rights/likeness checks, final references and final link access have not been verified here.
